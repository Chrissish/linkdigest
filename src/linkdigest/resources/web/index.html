打开方式不对

这个页面是 file:// 打开的静态文件， 它身后的后端（解析、转写、模型）一个都没在跑，所以点「生成总结」只会报资源找不到。

正确做法是从项目根目录把服务拉起来，然后用 HTTP 地址访问：

cd linkdigest && ./scripts/run.sh open http://127.0.0.1:8787

服务起好后点这里：http://127.0.0.1:8787/
